Per què usem comandes de xarxa? 6 min

Moltes tasques d'un tècnic de xarxes es fan escrivint comandes al terminal: una finestra on dónes ordres al sistema amb text. Serveixen per veure la configuració d'un equip, comprovar si hi ha connexió i trobar on falla una xarxa.

  • El terminal s'obre amb Ctrl + Alt + T.
  • Cada comanda s'escriu i s'executa amb Enter.
  • Si una comanda no acaba sola (com ping), s'atura amb Ctrl + C.
En aquesta pràctica es treballa amb LibreOffice en local, no amb Google Drive, perquè es perdrà la connexió en moure cables. Cada alumne treballa amb el seu propi document.
Veure la IP i la MAC: ip a, ifconfig i lsb_release 8 min
ComandaQuè fa
ip aMostra les interfícies de xarxa amb la IP i la MAC
ifconfigFa el mateix; cal tenir instal·lat el paquet net-tools
lsb_release -aMostra la versió del sistema operatiu

A la sortida de ip a busca la teva targeta de xarxa (per exemple enp3s0; la interfície lo és interna i té la 127.0.0.1):

2: enp3s0: <BROADCAST,MULTICAST,UP> ...
    link/ether 00:1a:2b:3c:4d:5e brd ff:ff:ff:ff:ff:ff
    inet 172.16.209.37/24 brd 172.16.209.255 scope global enp3s0
  • link/ether és la MAC (adreça física, gravada pel fabricant).
  • inet és la IPv4. El /24 equival a la màscara 255.255.255.0.
Comprovar la connexió: ping 8 min

ping envia petits missatges a un altre equip i espera la resposta. Serveix per saber si hi ha connexió i quant triga (en mil·lisegons, ms).

$ ping -c 4 172.16.209.38
64 bytes from 172.16.209.38: icmp_seq=1 ttl=64 time=0.45 ms
64 bytes from 172.16.209.38: icmp_seq=2 ttl=64 time=0.41 ms
  • Pots fer ping a una IP o a un nom (ping www.google.es). Amb un nom, el sistema obté la IP gràcies al DNS, que tradueix noms a adreces IP.
  • Sense opcions, el ping no s'atura: prem Ctrl + C. Amb -c 4 envia només 4 missatges.
  • Si desconnectes el cable, deixen d'arribar respostes i pot aparèixer un missatge com Network is unreachable o Destination Host Unreachable.
La taula ARP: arp -a 8 min

Dins d'una xarxa local els equips es comuniquen per MAC. El protocol ARP serveix per descobrir quina MAC correspon a cada IP: un equip pregunta a tothom (un broadcast) «qui té aquesta IP?» i el propietari respon amb la seva MAC.

Cada PC guarda el resultat a la seva taula ARP. La comanda arp -a la mostra. Només hi apareixen els equips amb qui t'has comunicat, per exemple després de fer-los un ping.

$ arp -a
? (172.16.209.38) at 00:1a:2b:3c:4d:6f [ether] on enp3s0
Els salts d'una ruta: traceroute, tracepath i mtr 10 min

Un salt és cada router pel qual passa un missatge fins al seu destí. Els switches no compten com a salt. Per això, si dos PC són a la mateixa xarxa, només hi veuràs 1 salt: el destí directe.

ComandaQuè fa
tracerouteMostra un a un els salts fins al destí (cal instal·lar el paquet traceroute)
tracepathAlternativa que sol venir instal·lada
mtrCombina ping i traceroute i s'actualitza en directe
$ traceroute www.google.com
 1  172.16.209.1   1.2 ms
 2  10.20.0.1      3.8 ms
 3  * * *

Els asteriscs * * * volen dir que aquell salt no ha respost a temps. Per veure els salts a un mapa pots fer servir l'aplicació web geotraceroute.com.

El default gateway: route -n 8 min

El default gateway (DG o passarel·la per defecte) és la IP del router més proper: la porta de sortida del PC cap a altres xarxes. Es pot veure amb route -n o amb ip route.

$ route -n
Destination   Gateway       Genmask        Flags Iface
0.0.0.0       172.16.209.1  0.0.0.0        UG    enp3s0
172.16.209.0  0.0.0.0       255.255.255.0  U     enp3s0

La línia amb destinació 0.0.0.0 i la marca UG és la ruta per defecte: la columna Gateway és el DG. Amb ip route el veus com default via 172.16.209.1.
