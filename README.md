# MP0255 Xarxes locals

Web del mòdul professional MP0255 Xarxes locals (CFGM Sistemes Microinformàtics i Xarxes), publicada amb GitHub Pages.

## Estructura

- `index.html`: pàgina principal
- `AEA/AEA1.html`: índex de l'AEA1; `AEA/A0.html` a `A5.html`: les activitats
- `assets/css/style.css`: estils
- `assets/docs/`: teoria en PDF (A2 a A5)
- `assets/img/`: imatges
