# MP0225 Xarxes locals

Web del mòdul professional MP0225 Xarxes locals (CFGM Sistemes Microinformàtics i Xarxes), publicada amb GitHub Pages.

## Estructura

- `index.html`: pàgina principal (AEA, resultats d'aprenentatge, avaluació i recursos)
- `AEA/`: una pàgina per AEA (`AEA1.html`, ...)
- `assets/img/`: imatges
- `assets/docs/`: documents i PDF
