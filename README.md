# MP0255 Xarxes locals

Web del mòdul professional MP0255 Xarxes locals (CFGM Sistemes Microinformàtics i Xarxes), publicada amb GitHub Pages.

## Estructura

```
MP0255/
├── index.html            ← portada del mòdul
├── assets/
│   ├── css/style.css
│   └── img/
├── AEA1/                 ← Reconeixement de l'estructura de les xarxes locals
│   ├── index.html
│   ├── A0.html ... A6.html
│   └── docs/             ← PDF de teoria
└── AEA2/                 ← AEA-2: Cablejat estructurat i R.L (RA2 + RA6)
    ├── index.html
    ├── B1.html           ← oberta
    ├── B2.html           ← bloquejada fins nou avís
    ├── img/              ← fotos i esquemes del tutorial del taller
    └── docs/             ← PDF de teoria i manual de riscos laborals
```

Cada AEA té la seva carpeta amb la mateixa estructura: `index.html`, les activitats i la carpeta `docs/`.
