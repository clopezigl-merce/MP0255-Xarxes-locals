Tipus de dispositius d'una xarxa 8 min

Els dispositius d'una xarxa local es divideixen en dos grans grups:

  • Hosts (equips finals): envien i reben informació. Per exemple, un PC, un portàtil, un servidor o una impressora de xarxa.
  • Dispositius d'interconnexió: connecten els hosts entre ells i amb altres xarxes. Són el hub, el switch, el router i el punt d'accés Wi-Fi.
DispositiuQuè faNivell (model OSI)
HubRepeteix el que rep per tots els altres ports1 · Físic
SwitchAprèn les adreces MAC i envia les dades només pel port del destinatari2 · Enllaç
RouterConnecta xarxes diferents i decideix el camí segons les IP3 · Xarxa
ServidorOfereix serveis (fitxers, web, correu…)Host

Els hubs ja gairebé no s'utilitzen, però els estudiem per entendre bé què aporta un switch. Els nivells OSI els veurem més endavant.

Hub i switch: la gran diferència 10 min

El hub no és intel·ligent: quan rep dades per un port, les copia a tots els altres ports. Tots els equips comparteixen el mateix canal, com una sala on tothom escolta tothom. Si dos equips parlen alhora, els missatges xoquen (col·lisió) i s'han de repetir.

El switch té una taula MAC on apunta quin equip hi ha a cada port. Quan rep una trama, mira la MAC de destí i la reenvia només pel port correcte. Així poden parlar diferents parelles d'equips alhora, sense xocar.

HubSwitch
Com envia les dadesA tots els portsNomés al port del destinatari
Col·lisionsSíNo (cada port és independent)
Ample de bandaEs reparteix entre totsCada port té el seu
Intel·ligènciaCapTaula MAC
Ús actualGairebé desaparegutEstàndard a qualsevol LAN
Si el switch encara no coneix la MAC de destí, la envia per tots els ports menys pel qual ha arribat, i aprèn la resposta.

Practica

Vertader o fals?

Decideix si cada frase és vertadera o falsa.

  • El hub envia les dades només al port del destinatari.

    El hub les copia a tots els ports; ho fa el switch.

  • El switch aprèn quina MAC hi ha a cada port.

    Ho guarda a la taula MAC.

  • Amb un hub, dos missatges enviats alhora poden xocar.

    Tots els ports comparteixen el mateix domini de col·lisió.

Què fa un switch quan rep una trama?

Usa les fletxes per ordenar els passos.

  2. Reenvia la trama només pel port del destinatari
  3. Apunta la MAC d'origen i el port a la taula MAC
  4. Busca la MAC de destí a la taula

Dominis de col·lisió i de broadcast 12 min

Un domini de col·lisió és la zona de la xarxa on dos missatges enviats a la vegada xoquen.

DispositiuDominis de col·lisió
HubTots els seus ports formen un sol domini
SwitchCada port és un domini
RouterCada interfície és un domini

Un missatge de broadcast (difusió) va dirigit a tots els equips de la xarxa. Per exemple, un PC que pregunta «qui té aquesta IP?» o que demana una IP automàtica. El domini de broadcast és el conjunt d'equips que reben aquests missatges.

DispositiuSepara dominis de broadcast?
HubNo
SwitchNo: reenvia el broadcast a tots els ports
RouterSí: no reenvia el broadcast d'una xarxa a una altra

Per això cada xarxa, cada port del router, és un domini de broadcast diferent.

Adreces MAC i adreces IP 10 min

La MAC és l'adreça física gravada pel fabricant a la targeta de xarxa. Té 48 bits, escrits com 6 parells hexadecimals: 00:1A:2B:3C:4D:5E. Els tres primers parells identifiquen el fabricant. Serveix per comunicar-se dins la mateixa xarxa local.

La IP és una adreça lògica, la configura l'administrador o el DHCP, i permet comunicar-se entre xarxes diferents.

MACIP (IPv4)
Mida48 bits32 bits
FormatHexadecimal: 00:1A:2B:3C:4D:5EDecimal: 192.168.1.20
Qui l'assignaEl fabricantL'administrador o el DHCP
Canvia?No (en general)Sí
AnalogiaEl número de sèrie de l'aparellL'adreça postal

Per veure-les: a Linux, ip a (la MAC surt a link/ether i la IP a inet). A Windows, ipconfig /all (la MAC és l'«Adreça física»).

Packet Tracer: IP, default gateway i ping 12 min

Per connectar dues xarxes necessitem un router amb un port a cada xarxa. Cada port del router té una IP de la xarxa a la qual està connectat. Normalment és la primera disponible, per exemple 192.168.1.1.

Cada PC té una IP de la seva xarxa, la màscara i el default gateway (DG): la IP del port del router de la seva xarxa. És la «porta de sortida» per arribar a altres xarxes.

ElementIPDefault gateway
PC1 (xarxa A)192.168.1.10192.168.1.1
Port del router a la xarxa A192.168.1.1—
PC5 (xarxa B)192.168.2.10192.168.2.1
Port del router a la xarxa B192.168.2.1—

El switch i el hub no necessiten IP per funcionar. El ping serveix per comprovar si dos equips es veuen: dins la mateixa xarxa funciona directament; entre xarxes diferents necessita el router i els DG.

A Packet Tracer, activa el port del router (Port Status: On) o no funcionarà.
